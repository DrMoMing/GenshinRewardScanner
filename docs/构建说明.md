# 独立构建

此入口不读取开发者机器的A14目录、debug、backup或原Git历史。配套构建支持包保存经校验的原生运行依赖、模型资源及旧预置基线，便于在复核源码时复用相同DLL。第三方源码与其原始构建说明在`third_party/native`。

环境：Windows x64、Python 3.13 x64、.NET Framework 4.8。构建安装器还需Inno Setup及中文语言文件。编译浮窗源码还需VS C++ x64工具链；默认重用支持包中已验证的浮窗二进制。当前Python依赖版本固定在`requirements-build.txt`。

从本版本Release下载 `build-support_0.3.0-preview.9.zip`，放在源码根目录的上一级，然后在源码根目录运行：

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe tools\build.py --support ..\build-support_0.3.0-preview.9.zip --check
.venv\Scripts\python.exe tools\build.py --support ..\build-support_0.3.0-preview.9.zip
```

可选生成安装包：将Inno Setup编译器目录加入PATH，在最后一条命令后加`--iscc (Get-Command ISCC.exe).Source`。安装脚本沿用产品标识，更新安装沿用原数据选择规则。

输出位于`dist/DomainScanner`。工具会验证支持包及每个内部文件的SHA256，并重新编译WPF桌面宿主。已存在输出目录时拒绝覆盖，使用新的源码副本进行下一轮构建。构建会占用额外磁盘空间。

修改Maa库时使用`third_party/native/rc77-input-source.zip`及其嵌套对应源码；查看`third_party/correspondence.json`中的实际DLL哈希，不能使用更早期DLL替代后宣称与发行相同。库可以独立替换，本项目许可不限制LGPL允许的库修改、替换和调试。

浮窗可在VS x64开发者命令提示符执行`native/overlay/build.cmd`重建到`.build/overlay/OverlayWindow.exe`。将重建结果用于发行时，需要重新验证其回调和原生显示，不把源码编译通过当成功能验收。

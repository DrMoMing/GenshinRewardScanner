# 资源与识别规则

## 详情布局

`src/artifact_layout.py`加载`Assets/原神/副本结算页/详情布局/文字候选.json`，结合实际像素对候选位置修正。`src/detail_geometry.py`、`src/domain_geometry.py`负责详情及页面几何；`src/domain_run.py`是生产调用入口。横排、详情各按其真实分辨率及几何处理，不靠拉伸画面隐藏比例差异。

名称模板与自然学习按角色、星级、原始宽高分组；+0固定模板也只在对应原始尺寸匹配，未确认时回原OCR。仅好感经验与摩拉两张用户提供的固定锚点沿用已有跨尺寸识别方案。

+0目前是三张固定的文字裁块，不会自动截取、替换或更新。`等级零模板/manifest.json`仅保留实际加载所需的`file`及原始分辨率`shape`；历史截图来源路径已删除。读取时相对于当前资源根目录取图，不依赖开发者电脑的目录。

## 运行资源

`src/material_icons.py`只读取三张图：`材料图标/高清原图/好感经验.png`、`材料图标/高清原图/摩拉.png`、`材料图标/原生小图/摩拉.png`。两份摩拉分别为256×256与64×64原图，像素不同；运行时生成的42组模板及掩码保留不变。未使用的72px派生、旧截图图标、角色经验与冒险阅历图片及采集记录已移出发行。

`准入图标`已移除；当前获得页准入使用标题与完整奖励横排，不使用体力弯月和锁定辅助模板。两个旧图标读取函数及过时自检要求也已删除。

数值表保留实际数值及使用范围说明，移除用户消息、更正日期等记录；其中一星防御力2.4没有改动。圣遗物对照表保留实际对照数据和来源URL，移除其他项目遗留的note。数字模型保留实际模型哈希、词表和推理信息，移除历史实验验证计数及训练检查点记录。

`Assets/原神/等级零模板`供等级+0快速匹配；其余详情布局、圣遗物对照及数值表、数字识别资源都是生产依赖，因此进入源码资源清单。

`Assets/原神/model/ocr`包含实际发行使用的模型。上游OCR基线来源与许可保留在`third_party/LICENSES/OCR来源.txt`及同目录的MaaCommonAssets-MIT、PaddleOCR-Apache-2.0原文。该历史原文的“未改模型”描述上游下载时的状态；本次实际`rec.onnx`已使用后续游戏字体微调模型，以文件清单哈希识别，不能将其描述为完全未经修改的上游权重。

模型微调结果、游戏文字裁块和界面图像不因此获得额外的游戏素材权利；游戏相关材料归各自权利人。本项目许可适用范围见`docs/licensing/许可适用范围.md`。

当前自然学习库快照放在审阅目录的`待讨论`中，未直接合入源码；运行后由本机积累的完整个人缓存不属于源码发布范围。

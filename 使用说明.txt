原神副本扫描器 0.3.0-preview.14



安装与启动

双击 DomainScanner_Setup_0.3.0-preview.14.exe，先确认 Windows UAC，再选择安装位置。

程序会建立独立的 DomainScanner 文件夹。启动 DomainScanner.exe 时确认管理员权限。

运行依赖已包含，无需另装 Python、MaaMCP 或 Codex。

安装只展开一次，日常启动直接使用已安装的运行依赖。
安装完成时会后台准备必要目录和初始设置，并检查 OCR 文件能否读取。

桌面界面使用 Windows 自带的 WPF / .NET Framework 4.8。



使用

在主页选择工作簿，留空时本次会话在“产出”下的“Excel”文件夹自动新建，并连续追加后续任务；文件名保持不变。

如果全局组合键无法直接录入，可在设置中右键其快捷键输入框，手动输入后按 Enter 检查。
点击“启动准备”，等待模型加载和快捷键监听就绪，然后切回游戏。

整趟 Ctrl+Alt+S，单卡 Ctrl+Alt+D，拼图 Ctrl+Alt+P。

中止当前任务 Ctrl+Alt+X，停止扫描监听 Ctrl+Alt+Q，浮窗锁定/解锁 Ctrl+Alt+O。

所有快捷键均可在设置页重新录入。中止在点击或拖动边界收口，保持鼠标松开。



输出与表格

截图、日志、JSON、扫描缓存和学习数据集中保存在安装目录。

自动新建的Excel位于产出/Excel，指定的工作簿位置不变。

详细日志、截图与结果JSON按任务归档，产出/总记录.log仅保存任务目录索引。

空间管理可清理成功或失败的已结束任务及其结果JSON；正在使用或保存待确认的资料仍保护。

跨任务通信日志按会话归档，长期学习库与Excel不随任务清理。

指定 Excel 文件时，只向所选工作簿追加；该工作簿所在文件夹不会生成扫描缓存和诊断文件。

桌面实时显示需要可用的 Excel/WPS 自动化接口。关闭实时显示时使用文件模式，目标工作簿须关闭。

JSON转Excel、图解与文字教程、第三方许可可在软件内查看。

数据列依次为序号、种类、数量、数量可信、名称、星级、部位、等级、主词条名称及数值、副词条数，留一列后列出副词条，套装位于末尾。

安装包附带1920×1080成功基线及自然学习样本。基线会校验当前画面，学习库保留实际校验进度，已有缓存优先保留。



空间与错误

空间页可手动清理批次，也可开启按批数或1/3/7/15/30天保留。

清理会保护仍在处理或保存待确认的资料；已结束任务的截图、日志和结果JSON可一起清理，Excel和长期学习库保留。

错误导出只关联所选失败或异常任务的资料，缺失资料会在ZIP说明中标注。



声音与浮窗

单卡拍摄使用削弱高频的快门声；任务成功与失败使用各自的四音提示。

声音可关闭或试听。浮窗透明度、捕获排除和性能显示可独立设置。



安装和卸载

发现已有安装时，在原目录移除旧程序并安装新版，无需手动搬移数据。

覆盖及卸载默认保留工作簿、产出、设置和缓存，也可主动选择全部清除。清除范围仅限扫描器安装目录；外部指定的Excel始终保留。侧栏底部“卸载”会先退出扫描器再打开卸载程序。



本版状态

新版界面、声音及空间管理已做源码和冻结EXE回归。

实际游戏和桌面Office结合新版界面的验收仍需进行。

自定义提示音
目录：%LOCALAPPDATA%\DomainScanner\提示音（不存在就新建）。
截图成功：截图.wav 或 截图.mp3。
扫描任务成功：成功.wav 或 成功.mp3。
扫描任务失败：失败.wav 或 失败.mp3。
指令未接收：未接收.wav 或 未接收.mp3。
每段最多 3 秒。同名时优先 WAV；缺失或不可读时用内置音。替换后重启扫描器。

应用内入口：设置 → 提示音 → 打开提示音文件夹。详见「详细文字教程 07」。
便携目录内的「提示音试听样例」可选用；不会自动替换当前提示音。
